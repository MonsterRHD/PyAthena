# Repository scripts

Run the Python checks, ShellCheck, actionlint, and offline script tests from the repository root:

```bash
mise install shellcheck actionlint
just scripts
```

ShellCheck is pinned in `.mise.toml` and checks `scripts/*.sh`.
The pinned actionlint checks GitHub Actions workflows, including embedded shell commands.
The script tests under `scripts/tests/` use botocore stubs and require no AWS credentials.

## Expired test databases

`sweep_databases.py` previews expired test databases in the caller's default Glue catalog.
It uses the normal Boto3 credential and region configuration.

```bash
AWS_PROFILE=<profile> AWS_DEFAULT_REGION=<region> uv run --locked --no-dev python scripts/sweep_databases.py
```

Add `--apply` to delete eligible database metadata.
Eligibility requires a complete match for the database names generated by the PyAthena or SQLAlchemy test fixtures and a creation time more than seven days old.
Resource links and federated databases are excluded.
The script completes inventory before deleting and rechecks eligibility and creation time immediately before each deletion.
Only missing-database errors are ignored; permission and other API failures stop the sweep.
Deleting a database also removes its Glue table metadata; S3 objects are not deleted.

The **Sweep test databases** workflow runs after the weekly **Test** workflow completes on `master`, including failed or cancelled runs.
It does not run after pull request tests or manually dispatched tests.
Manual dispatch of the sweep is available on `master` and defaults to a preview.
The sweep has a 15-minute job timeout and reports aggregate counts.
A timeout or API failure can leave eligible databases for a later run.
